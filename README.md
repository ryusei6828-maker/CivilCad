# CivilCad

土木向けの 2D CAD (Windows / C# .NET 10 / WPF)。

## 構成

| プロジェクト | 内容 |
|---|---|
| `src/CivilCad.Core` | 幾何 (Vec2, Box2)、図形、レイヤ、図面、Undo/Redo |
| `src/CivilCad.Alignment` | 路線計算 (IP法・クロソイド・測点・縦断曲線)。UI に依存しない |
| `src/CivilCad.App` | WPF アプリ (作図画面、ツール、レイヤパネル、路線計算ダイアログ、DXF 入出力) |
| `tests/CivilCad.Tests` | xUnit テスト |

## 実行

```
dotnet run --project src/CivilCad.App
dotnet test
```

### 配布用 exe の作成

.NET 同梱の単一 exe (`publish\CivilCad.exe`、インストール不要) を作る:

```
dotnet publish src/CivilCad.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=None -o publish
```

## 座標系

- CAD 内部座標: **x = 東, y = 北** (m)。コマンド欄の座標入力もこの順。
- 路線計算ダイアログ・計測結果の表示は測量座標 **X = 北, Y = 東**。
- 方向角は測量の定義 (北 = 0°, 時計回り)。

## 操作

画面上部のツールバーは、左に いつも使うボタン (選択・新規・開く・保存・戻す・やり直し)、右に種類ごとのタブがあります:
**描画** (線・ポリライン・円・円弧・矩形・点・垂線・寸法・ハッチング・塗りつぶし・プリセット)、**文字** (文字・文字変更・引き出し線・旗揚げ)、**修正** (移動・複写・回転・拡大縮小・2 点指示・オフセット・トリム・延長・結合)。**削除** は選択の隣にいつも出す、**図面** (図枠・縮尺・座標・座標系・座標読込)、
**計測** (距離・面積)、**路線** (路線計算・XML 読込・測点照会)、**表示** (全体表示・レイヤ・プロパティ)。
メニューも同じ分け方です。

| 操作 | 方法 |
|---|---|
| ズーム / パン / 全体表示 | ホイール / 中ボタンドラッグ / 中ボタンダブルクリック |
| 選択 | クリックでその図形だけを選択、Shift+クリックで追加 (選択済みなら解除)、ドラッグで範囲選択 (ドラッグの向きは問わない。Shift+ドラッグで追加)、空き部分クリックで選択解除。文字を選ぶとプロパティ (右側) が開き、中身・大きさを変えられる |
| 範囲選択の方法 | 右下の「範囲選択」で **全体** (範囲に完全に入る図形) / **一部** (範囲に少しでもかかる図形) を切り替え。削除モードも同じ。設定は次回も引き継ぐ |
| スナップの種類 | 右下のスナップツールバー: 「スナップ」で全体のオン/オフ、右の 端点・中点・中心… の各ボタンで種類ごとにオン/オフ |
| 座標入力 | `x,y` 絶対、`@dx,dy` 相対、`@距離<角度` 極座標 |
| スナップ / 直交 | F3 / F8 (スナップの種類は右下のスナップツールバー、または 設定 > スナップの種類) |
| 元に戻す / やり直し | Ctrl+Z / Ctrl+Y |
| コマンドのキャンセル | Esc (作図領域・コマンド欄のどちらにカーソルがあっても効く) |
| 連続作図 | コマンドは 1 つ描いても終わらず、Esc を押すまで続けて使える (円・円弧・文字・ポリライン・ハッチング・垂線・計測・移動など)。線・ポリラインは Enter でその線を終えて次の線へ、何も描いていないときの Enter はコマンド終了 |
| 右クリック | コマンド中: **一つ戻す** (直前に指定した点を取り消す。線では引いた線も消える)・**最初からやり直す**・確定 (ポリラインの確定など)・コマンドを終了。選択中: 移動・複写・拡大縮小・削除・選択解除、元に戻す / やり直し |
| 一つ戻す (キー) | コマンド欄が空のとき Backspace |
| 選択モード | ツールバー左端の「選択」(矢印、`SEL`) か Esc。右クリックメニューの一番上の「選択モード」でも切り替えられる (選択モード中の右クリックでは範囲選択の 全体 / 一部 も選べる)。実行中のコマンドを終えて、クリックで 1 つ選択・ドラッグで範囲選択 (全体 / 一部 は右下の「範囲選択」)・Shift+クリックで追加・解除。選択モードの間は「選択」ボタンが色付きになる |
| コピー・貼り付け | 図形を選んで **Ctrl+C** (コピー) / **Ctrl+X** (切り取り) → 貼り付けたいシートに切り替えて **Ctrl+V** で同じ位置 (同じ座標) に、**Ctrl+Shift+V** で位置を指定 (コピーした図形の左下を基点にクリック、続けて何個でも) して貼り付け。別のシートにも貼り付けられる。図形は同じ名前のレイヤに入り (無ければ同じ名前・色で作る)、座標設定 (CS) の向きがシートで違うときは測量座標が同じになる位置に置く。右クリックメニュー・修正メニューからも (`CB` / `CUT` / `PA` / `PAP`)。コマンド欄に文字があるときや表の中では、そちらのコピー・貼り付けになる |

コマンド: `L` 線, `PL` ポリライン (`C` で閉じる), `C` 円, `A` 3点円弧, `REC` 矩形 (1 つ目の角 → 対角の角、`@幅,高さ` でも可。閉じたポリラインになる), `PO` 点 (クリックか座標の入力 x,y / @dx,dy / s X,Y で置く。続けて置ける。画面では大きさ一定の黒丸、印刷は φ0.5mm、スナップは「点・挿入点」。DXF・DWG・JWW (実点)・SFC / P21 (点マーカー) で読み書き), `PE` 垂線, `T` 文字 (`H=数値` で大きさ。既定は用紙上の mm、下記), `H` ハッチング, `FI` 塗りつぶし, `J` 結合,
`M` 移動, `CO` 複写, `RO` 回転 (中心点 → 基準の方向点 (今の向き) → 回転先の方向点 (新しい向き) の順に指定。方向点の代わりに角度 (度、反時計回りが +) を入力しても可。C で元を残す。回転コマンドの間だけ、文字の枠 (テキストボックス) の 4 隅・各辺の中点・中心にもスナップする), `SCL` 拡大縮小 (右のプロパティでやり方を選ぶ。**倍率を指定**: 倍率を入れて Enter → 基点をクリック (基点が先でも可。参照する長さを 2 点で指定してから新しい長さを入力 / クリックも可)。**2 点を合わせる**: 選んだ図形の 2 点 → 合わせ先 (別の図形) の 2 点をクリックすると、1 点目どうしが重なり 2 点間の長さが同じになる (向きはそのまま。「向きも合わせる」で回転も)。文字の高さ・円の半径・ハッチの間隔・プリセットの大きさ・画像も一緒に変わる), `AL` 2 点指示 (位置合わせ。画像の項を参照), `O` オフセット, `TR` トリム, `EX` 延長, `ED` 文字変更, `E` 削除モード (クリックで消す図形を選び (もう一度クリックで解除)、ドラッグで範囲内の図形をまとめて選ぶ (全体 / 一部 は範囲選択の方法に従う)。選んだ図形は赤く表示され、**ダブルクリック** (または Enter) で削除。1 回のクリックでは消えない。Esc で選んだものを解除、もう一度 Esc で終了。削除モードに入るときに選択中の図形は消さず、選択を外す), `DI` 距離・方向角, `AA` 面積, `RC` 路線計算, `ST` 測点照会, `ZE` 全体表示

### 文字の大きさ

文字ツール (`T`) の文字は、既定で **用紙上の mm** (既定 3.5mm) を図面の縮尺で m に換算した大きさで書きます。拡大・縮小すると線と一緒に大きく・小さくなります。
作図入力バーの「画面で一定の大きさ」をオンにすると、拡大率によらず画面上で一定の大きさ (既定 16px) になります。
プロパティの「画面で一定 (px)」で文字ごとに切り替えられます (空欄にすると今の大きさで図面に固定)。
ファイルに保存するときは、画面で一定の文字を用紙上 1px = 0.26mm の大きさ (縮尺で換算) にして書きます。

**フォント**: 文字ツールの作図入力バーの「フォント」で、これから書く文字のフォントを選べます (既定は ＭＳ ゴシック)。
書いた文字はプロパティの「フォント」で変えられます (複数まとめて可)。一覧にはこの PC のフォントが出ます (ＭＳ 明朝・BIZ UD ゴシック・游明朝などを先頭に)。
DXF / DWG (文字スタイル)・SFC (文字フォント)・JWW (書体名)・PDF 印刷に書き出し、読み込みでも取り込みます。
この PC に無いフォントは ＭＳ ゴシックで表示します。文字の幅 (選択の範囲など) は等幅の目安で計算するので、プロポーショナルフォントでは実際の文字より少し広くなります

### 文字の入力

- **文字** (`T`): コマンドを選んで図面にカーソルを合わせると、カーソルの位置 (左下) に今の大きさの文字枠と「文字」の見本が付いて動きます。
  置きたい所でクリックすると、その場所に入力欄が出るので、そのまま文字を打って Enter で置きます (Esc でやめる)。
  入力中に別の場所をクリックすると、入れた文字を置いて次の位置の入力に移ります。Esc を押すまで続けて置けます
- **引き出し線・旗揚げ**: 文字は右のプロパティの一番上の入力欄で入れます (Enter で確定、Shift+Enter で改行、Esc でやめる)
- 下のコマンド欄に打っても今までどおり置けます

### 寸法

描画タブの「寸法」(`DIM`) で長さの寸法を記入します: 1 点目 → 2 点目 → 寸法線の位置 をクリック。
置いたあと続けてクリックすると、前の 2 点目からの寸法を同じ寸法線の上に並べます (直列寸法)。Enter で新しい寸法、Esc で終了。

- 入力バー: 向き (平行 = 2 点を結ぶ向き / 水平 / 垂直)・端末 (矢印 / 黒丸 / 斜線)・単位 (m / mm)・小数桁・文字高・端末の大きさ (用紙 mm)
- 寸法値は計った長さから自動で書き、図形を拡大縮小すると書き換わります。プロパティの「寸法値」で文字を書き換えられます (`<>` は計った長さ。例: `L=<>`)
- 1 つの図形として移動・回転・削除でき、プロパティで単位・桁数・文字高・端末を変えられます
- DXF・SFC・JWW などには補助線・寸法線・端末・文字に分けて保存します

### 引き出し線・旗揚げ

描画タブの「引き出し線」(`LD`)・「旗揚げ」(`HA`) で注記を描きます。どちらも 1 つの図形として選択・移動・回転・削除でき、プロパティで文字・文字高・先端の形を変えられます。

- **引き出し線**: 先端 → 折れ点 (いくつでも) をクリックして Enter → 文字を入力 (行ごとに Enter、空のまま Enter で確定。文字なしも可)。
  文字は最後の点の先 (線の向きの側) に横書きで置きます
- **旗揚げ**: 先端 → 旗竿の始まり をクリック → 文字を入力 (行ごとに Enter、空のまま Enter で確定)。
  旗竿 (水平線) は先端と反対側へ文字の幅だけ自動で引き、その上に文字を積みます (1 行目が一番上)
- 「|」で区切ると 1 回の入力で複数行を入れられます (例: `As=D13@200 | L=12.5m`)
- 入力バーで先端 (矢印 / 黒丸 / なし)・文字高・先端の大きさ (用紙 mm) を選べます。回転しても文字と旗竿は水平のまま
- DXF・SFC・JWW などには線・塗り (先端)・文字に分けて保存します

### 修正コマンド

| コマンド | 使い方 |
|---|---|
| 回転 `RO` | 図形を選択 → 基点 → 角度を数値 (度、反時計回りが +) で入力するか向きをクリック。`C` で元を残して回転複写 |
| オフセット `O` | 距離 (m) を入力 → 図形をクリック → ずらす側をクリック。距離はそのまま続けて使える。線・円・円弧・ポリライン (角は留め継ぎ) |
| トリム `TR` | 境界にする図形をクリックして Enter (何も選ばず Enter で全図形。先に選択していればそれが境界) → 切り取る部分をクリック。Shift+クリックで延長 |
| 延長 `EX` | 境界を選んで Enter → 伸ばす端の近くをクリック。線・円弧・開いたポリライン。Shift+クリックでトリム |
| 文字変更 `ED` | 文字をクリックすると、入力の窓で中身を変えられる (Enter で変更、Esc でやめる)。続けて別の文字も変えられる。選択中 (コマンドを使っていないとき) は文字のダブルクリックでも。色・位置・大きさはそのまま。Ctrl+Z で戻せる |
| 結合 `J` | 図形を選択して実行。同じ直線上の線は 1 本に (間が空いていても埋める)、同じ円上の円弧は 1 つに (一周すれば円)、そのうえで端点が用紙上 0.05mm 以内でつながる線・開いたポリライン・円弧を 1 本のポリラインに (円弧は細かい折れ線になる。始点に戻れば閉じ、塗りつぶし (FI) の範囲に使える) |

トリム・延長はカーソルを合わせると、消える部分を赤、伸びた形を水色で先に表示します。
オフセットしたポリラインが自己交差しても整理しません。

スナップの「頂点」はポリラインの途中の点 (閉じたポリラインは全点) です。開いたポリラインの始点・終点は「端点」。

### ハッチング

ハッチングは 1 つの図形 (境界 + 平行線の模様) として扱い、ハッチ線をクリックすると全体がまとめて選ばれます
(移動・複写・削除・レイヤ変更もまとめて)。選択中は境界も表示します。
プロパティでは種類・面積を表示し、角度と間隔 (用紙 mm) を変更できます。

作図は 描画 > ハッチング (`H`):
- 閉じた図形 (閉じたポリライン・始点に戻るポリライン・円) の**内側をクリック**すると、その範囲にハッチング。
  いちばん小さい囲みが外形になり、その内側にある閉じた図形は中抜き (島) になります。カーソルを乗せると対象の範囲を破線で表示
- 閉じた図形が無い所では、**クリックした点を頂点**とする範囲を作り、Enter (または右クリック > 範囲を確定) で確定
- 作図入力バーで 種類 (斜線 / クロス / 塗りつぶし)・角度 (°)・間隔 (用紙 mm、縮尺で m に換算)・透明度 (%) を指定。Esc で終了
- **透明度**: 0% = 不透明、50% = 半透明。プロパティでも変更でき (複数のハッチングをまとめて変更可)、DXF に保存されます (SFC には透明度が無いため保存されません)。
  塗りつぶしは線・文字より下に描くので、塗っても線や文字は隠れません

### 塗りつぶし・結合

- **結合 (`J`)**: 端点どうしがつながった線・開いたポリライン・円弧を選択して実行すると、1 本のポリラインになります
  (順番・向きがばらばらでも可、用紙上 0.05mm までの隙間はつながっているとみなす)。一周して始点に戻れば閉じた図形になります。円弧は細かい折れ線になります
- **塗りつぶし (`FI`)**: 閉じた図形 (閉じたポリライン・円) を選択してから実行すると、まとめて塗ります (選択した図形の内側にある選択図形は中抜き)。
  選択せずに実行した場合は、塗りたい範囲の内側をクリック (ハッチングと同じ)。色は 作図の設定 (入力バー・プロパティ) の色、透明度は入力バーで指定
- 例: ばらばらの線で囲った範囲を塗る → 線を選択 → `J` で結合 → そのまま `FI`

### 計測結果の記入

距離 (`DI`)・面積 (`AA`) で計測すると、結果の文字 (例: `L=12.345m`、`A=123.456m²`) がカーソルに付いて動き、クリックした位置に置けます。
距離の文字は計測した線に沿った向き (逆さまにならない向き)、面積の文字は水平です。Enter で置かずに次の計測へ、
右クリック > 一つ戻す で計測の最後の点に戻れます。置いた文字は普通の文字として編集・移動できます (Ctrl+Z で取り消し)。
作図入力バーで「結果を文字で記入」のオン/オフ、文字高 (用紙 mm)、小数桁、方向角 / 周長も記入するかを設定できます。色・線幅は作図の設定のもの。

**計測結果は図面上の長さそのもの (実寸)** です。図面は実寸 (m) で描いているので、縮尺は掛けません (縮尺は印刷の大きさ・文字高・図枠の換算にだけ使う。例: 1:100 の A3 図枠は端から端まで 38m)。
単位は入力バーで mm / cm / m から選べます。

### プリセット (方位記号など)

`PS` (描画 > プリセット): 入力バーで種類 (方位記号 矢印・円 / シンプル / 十字)・大きさ (用紙 mm)・向き (°) を選び、クリックした位置に置きます。
Esc を押すまで続けて置けます。記号は 1 つの図形として選択・移動・複写・削除でき、プロパティで大きさ・向きを変えられます。
大きさは用紙上の mm なので、図面の縮尺によらず用紙上 (図面全体を見たとき) 同じ大きさになり、あとで縮尺を変えても用紙上の大きさは保たれます。
方位記号の N は常に北を指します (置いた後に移動・回転しても、系を変えても自動で合わせ直す)。入力バーの「北」で
真北 (平面直角座標の系から子午線収差を補正。系が未設定なら図面の上) / 座標北 (図面の上) を選べます。登録したプリセットは入力バーの向き (°) で置きます。
向きを手で決めたいときは **方位記号の向き (手動)** (`NM`): 方位記号を選択して実行し、N を向ける方向をクリック (または角度を入力) します。
手動にした方位記号は移動・回転しても北に合わせ直しません。**方位記号を北に合わせる (自動セット)** (`NA`) で北に戻り、以後また自動で北を指します
(選択が無ければ手動にした方位記号すべて)。プロパティでも手動の角度を入れたり、「自動」と入力して戻したりできます。DXF・SFC には線・塗り・円・文字に展開して保存します (他の CAD でも表示できる)。

**プリセット登録** (`PSR`、描画 > プリセット登録): 図形を選択してから実行し、基準点 (置くときにカーソルが付く点。Enter で選択範囲の中心) を指定して名前を入力すると、
選んだ図形 (線・ポリライン・円・円弧・文字・ハッチング・塗りつぶし・プリセット) がプリセットの種類に加わります (一覧では ★ 付き)。
- 登録時の大きさ (図形全体の幅・高さの大きい方の用紙上 mm) で置くと元と同じ大きさになります。色を指定していた図形はその色を残します
- 「選択した図形をこのプリセット 1 つに置き換える」をオンにすると、選んだ図形が記号 1 つにまとまります (元に戻すで戻せます)
- 登録したプリセットは `%APPDATA%\CivilCad\presets.json` に保存され、次に起動したときも使えます。
  プリセット (PS) の入力バーで登録したものを選ぶと「削除」ボタンが出ます (図面に置いたものは残ります)

### 垂線

`PE` (描画 > 垂線): **基準の線** (線・ポリライン・円・円弧) をクリック → **線上の点** (垂線の足。スナップ可、線の延長上も可) を指定 → **終点** を指定。
足に直角の印を表示します。円・円弧では中心を通る向きに引きます。入力バーの「長さ」を入れると、終点はクリックした側にその長さで決まります。
1 本引くと同じ基準の線のまま続けて引けます (別の線にするには右クリック > 一つ戻す、終了は Esc)。

ファイル:
- SFC: ユーザ定義ハッチング (fill_area_style_hatching_feature) を模様ごと読み書き。既定義ハッチングは 45° の斜線 (用紙 2mm 間隔) で表示
  (CAD が用紙外に置く管理用の "Area_control" は読みません)。中抜きのある塗りつぶしも読み込みます
- DXF: HATCH を読み書き (境界の線・円弧・楕円・ポリライン・スプラインに対応)。破線の模様は実線で表示
- 他の CAD がハッチングを 1 本ずつの線に分解して保存した図面は、ただの線として読み込まれます

### シートタブ

図面ごとにタブ (シート) で開きます。新規 (Ctrl+N / タブ右の ＋)・開くは新しいタブになり (空のタブは使い回し)、
同じファイルを開くとそのタブに切り替わります。各タブにはファイル名と縮尺・平面直角座標系 (例: 1:500 ・ II系) を表示し、
タブバー右端に表示中のシートの縮尺・座標系を出します (クリックで変更)。
未保存のタブには * が付き、閉じるとき・終了時に確認します。Ctrl+Tab / Ctrl+Shift+Tab で切り替え、タブの × か中ボタンで閉じます。
表示位置・路線データはシートごとに保持します。

### ファイル

- 開く・保存: DXF / DWG / JWW (Jw_cad) / SFC・P21 (SXF レベル2)。P2Z (P21 の ZIP) も開けます。
- 開くときは「図面の縮尺を選んで読み込む」窓が出ます。ファイルの縮尺 (SFC・P21・JWW と、DXF / DWG の $DIMSCALE) が初期値で、
  読み込んだときの実寸と用紙上の大きさ (収まる A 判) を見ながら縮尺を選べます。ファイルと違う縮尺にすると、用紙上の大きさのまま実寸が変わります (図寸固定。1:100 の図面を 1:250 で読むと 10m の線は 25m)。
  DXF / DWG は座標の単位も選べます: 実寸 m (CivilCad の DXF)・実寸 mm / cm (AutoCAD など。$INSUNITS があれば初期値)・用紙上の mm (図寸。縮尺を掛けて実寸に)。
  CivilCad の DXF / DWG は単位を m ($INSUNITS = 6) と書きます。
- P21: STEP AP202 (ISO 10303-21)。SCADEC のライブラリの書き方 (SFC のフィーチャ 1 つ = 決まった形のインスタンスの組) に合わせ、
  保存は SFC と同じ内容を AP202 に直したもの、読み込みは AP202 を SFC のフィーチャに直して SFC と同じ取り込み方をします。
  寸法は SFC と同じく、長さ寸法の寸法線と値・引出線と文字・その他の寸法とバルーンの文字を取り込みます。
- DWG: AutoCAD R14 以降の形式を読み込み (ACadSharp)。線・ポリライン・円・円弧・楕円・スプライン (折れ線)・文字・MTEXT・
  ハッチングとレイヤ・色・線幅を DXF と同じ対応で取り込み、ブロック参照は分解します。保存は AutoCAD 2013 形式。
- JWW: Jw_cad の公開データ形式 (jwdatafmt.txt) による。JWW の座標は用紙 mm (原点は用紙の中心) なので、
  「図寸 mm × レイヤグループの縮尺 / 1000」で実寸 (m) に換算します。レイヤは「グループ-レイヤ 名前」(16 進、例 `0-1 中心線`)。
  線・円・円弧・楕円 (折れ線)・実点 (小さな円)・文字・寸法 (線と値)・ソリッド (塗りつぶし)・ブロック (分解) に対応。
  保存はデータ版 700 (Jw_cad 7 以降) で、図面の縮尺を全レイヤグループに使い、用紙は SFC と同じ選び方で、その中心を原点にします
  (図面の元の座標はファイルメモに入れ、CivilCad で読み直すと元の位置に戻ります)。ポリラインは線分、ハッチングの模様は線、
  塗りつぶしは三角形のソリッドになります。「g-l 名前」のレイヤはそのグループ・レイヤに、ほかは空いているレイヤに入ります。
- SFC 保存時は、表題欄・図枠 (レイヤ D-TTL*) を用紙 (mm) に直接、それ以外を図面縮尺の部分図 (実寸 mm) として書き出します。
  レコードの並びは他の CAD (SCADEC) と同じ「定義 → 部分図 → 用紙上の図形 → 用紙 (drawing_sheet) → レイヤ表」。
  レイヤ名は前後の空白を除き、重複は「_2」などで区別、空なら「レイヤn」にして書きます。図形の無いレイヤ "0" は書きません (最大 256 レイヤ)。
  用紙は図枠から A 判を判定 (図枠が無ければ図形が収まる A 判)。白は黒として出力。Shift_JIS に無い文字は \X2\ 表記。
- SFC は用紙 (mm) 上に部分図を配置した形式なので、部分図の縮尺 (例: 1/500) を図面の縮尺とし、
  全体を「用紙 mm × 縮尺 / 1000」で実寸 (m) に換算して取り込みます (部分図の中身は元の実寸に戻る)。
  線・折線・円・円弧・楕円・文字・スプライン・クロソイド・点マーカー・引出線・寸法値・塗りつぶし・シンボル (sfig) に対応。
  ハッチングはハッチング図形として読み込みます (下記)。寸法の補助線・矢印は省略します。

### PDF に印刷

ファイル > PDF に印刷 (`PDF`、Ctrl+P) で、印刷範囲・用紙・向き・縮尺・白黒・既定の線幅を選んで PDF に書き出します。

- 用紙は自動 (図枠があればそれに合う A 判、無ければ図形全体が余白付きで収まる A 判) か A0〜A4。縮尺は既定で図面の縮尺
- 線・文字はベクトルのまま。画面の白い線 (暗い背景用の既定色) は黒で、非表示のレイヤは印刷しません。塗りつぶしは線の下に描き、透明度も反映します
- 線幅は図形の線幅 (mm)、指定の無い図形は既定の線幅。白黒にすると線はすべて黒、塗りは灰色の濃さになります
- 文字は既定で形 (アウトライン) で描きます (日本語のフォントを埋め込むと数 MB 大きくなるため)。「文字を検索・コピーできるようにする」でフォントを埋め込めます
- 画面で一定の大きさの文字は、保存と同じく用紙上 1px = 0.26mm の大きさで印刷します
- 印刷範囲: **図面全体** (図枠があれば図枠)・**今の画面**・**選択した図形だけ** (先に選択していればこれが最初に選ばれる)・**範囲を指定** (「範囲を指定する」を押して図面上で対角の 2 点をクリックすると、設定の窓がもう一度出る)。範囲の外・選択していない図形は印刷しません
- 「用紙に合わせて拡大・縮小する」をオンにすると、範囲が用紙 (余白 10mm) にちょうど収まる縮尺で印刷します (A3 / A4 に画面全体を収めるなど。用紙が自動なら A3)。使った縮尺は窓の下とメッセージ欄に出ます
- プリセット (方位記号など) と画像 (JPG / PNG / TIFF、PDF のページ) も印刷します。画像は用紙上 300dpi 相当。画像は高画質の JPEG (画質 95) で書き、「画像を劣化なしで保存する」で可逆圧縮 (ファイルは大きくなる)

### 座標管理

ツールバーの「座標管理」タブ (`CM`) を開くと、登録された座標の一覧 (点名・X (北)・Y (東)・Z) が左側に出ます。
登録された座標は点名のある点で、座標読込 (`PI`) の点・路線の幅杭・点 (`PO`。点名は P1, P2 … を自動で付ける)・座標計測 (`ID`) が入ります。

**座標計測** (計測タブ「座標」、`ID`): クリックした点 (スナップ可) の測量座標 X (北)・Y (東) (系があれば緯度経度も) をメッセージ欄に出し、
点名 P1, P2 … を付けて座標管理に登録します。続けて点名を入力すると直前の点の名前を変えます。続けて計測でき、一つ戻すで直前の登録を取り消します。
右クリックで「座標管理に登録する」をオフにすると、座標を見るだけになります。

- 座標は測量座標 (座標設定の向きを含む)。一覧で点名・X・Y・Z・タグを直すと図面の点も動きます (Z は空で標高なし。Ctrl+Z で戻せる)
- **タグ**: 点ごとに分類 (例: 幅杭・境界・BM) を付けられます。カンマか空白で区切って複数も可。「タグで絞り込み」でそのタグの点だけを一覧に出し、
  書き出しも一覧に出ている点 (選んでいれば選んだ点) だけになります。「登録するタグ」に入れておくと、点 (`PO`)・座標計測 (`ID`) で登録する点に付きます。
  幅杭は「幅杭」、座標読込は CSV の座標の後ろの文字の列 (備考など) がタグになります
- 一覧で選んだ点は図面でも選択されます。「削除」で図面から消す、「表示」で選んだ点 (選んでいなければ全部) が見えるように拡大
- 「CSV 出力」(`CEX`): 点名,X,Y,Z,タグ の CSV (UTF-8。読み込むとタグも戻る)、「SIMA 出力」(`SEX`): SIMA の A01 (Shift_JIS)。一覧で選んでいれば選んだ点だけ書き出します
- 幅杭の点名は「路線名 測点 左 / 右 幅」(例: `路線1 No.3 左5.5`)。路線を作図し直すと幅杭の点も作り直します
- 点名・標高・タグは DXF / DWG に保存します (SIMA にはタグの欄が無いのでタグは書きません)。
  SFC / P21 は点に点名・標高の欄が無いので、点の右上に点名、右下に「H=標高」の文字 (用紙上 2.5mm、レイヤ 座標-点名 / 座標-標高) を書き、
  CivilCad で開くと点のすぐ横のその文字を点名・標高に戻します (文字を動かすと戻りません。タグは残りません) (JWW・SFC・P21 では点名・標高は残りません)

### 座標読込 (SIMA / CSV)

ファイル > 座標読込、図面タブの「座標読込」(`PI`) で座標ファイルの点を図面に配置します。
読み取った点の一覧を確認してから、レイヤ (既定「座標点」)・点名 / 標高の表示・文字高 (用紙 mm)・点の印の大きさを選んで読み込みます。
点は小さな円 (中心にスナップ可) と点名の文字で、測量座標 (X = 北, Y = 東) の位置に置きます。元に戻すで一度に消せます。

- SIMA (.sim): `A01,点番号,点名,X,Y,H` の行。画地 (D00〜D99 の B01) があれば点をつないだ閉じた線も作れます
- CSV (.csv / .txt): 1 行 1 点。区切りはカンマ・タブ・空白。`点名,X,Y[,Z]`、`点番号,点名,X,Y[,Z]`、`X,Y[,Z]`、`点番号,X,Y,Z`、
  `No,点番,点名,X,Y,Z` などの並びを自動で判別し、見出しなど座標の無い行は飛ばします。座標の順は X (北), Y (東)
- 文字コードは Shift_JIS / UTF-8 を自動判別

### 画像 (読込・トリミング・2点位置合わせ)

図面タブの「画像」(`IMG`、ファイル > 画像) で画像コマンドに入ります。画像の読込・トリミング・2点位置合わせは、すべてこのコマンドの中で行います。
画像をクリックして選び、作図領域の上のバーのボタン (または `I` 読込 / `C` トリミング / `A` 2点位置合わせ / `R` トリミング解除 の入力、右クリック) で操作を選びます。
各操作を終える (または Esc でやめる) と画像コマンドに戻るので、読込 → トリミング → 位置合わせ と続けて行えます。画像コマンドの中で Esc を押すと画像コマンドを終えます。
(`IM` で読込、`IC` でトリミングから始めることもできます。2 点指示 `AL` は画像以外の図形にも使えるので、修正タブにも残しています。)

写真やオルソ画像、PDF を図面に置きます (JPG・PNG・TIFF・BMP・GIF・PDF)。

- PDF は 1 ページを画像として置きます (複数ページならページを選ぶ)。左下の点 → 幅を指定し、Enter で原寸 (図面の縮尺で用紙の大きさ。
  1:500 なら A1 横 841mm → 420.5m) になるので、同じ縮尺の PDF 図面を重ねるときは位置を合わせるだけで済みます。
  拡大すると見えている範囲を細かく描き直すので、図面の細い線や小さな文字も読めます。パスワード付きの PDF は読めません

- ワールドファイル (`.jgw` `.tfw` `.pgw` `.jpgw` `.wld` など) か GeoTIFF の位置情報があれば、その座標 (x = 東, y = 北) に置きます
- 位置情報が無ければ、左下の点 → 下辺の向きと幅 (2 点目のクリック、または幅を m で入力) を指定します。Enter で既定の大きさ (1 画素 = 用紙 0.1mm)
- **2 点指示** (`AL`、修正タブ「2点指示」・選択中の右クリック): 画像 (枠をクリックして選択) を選んで実行し、
  画像の上の 1 点目 → 図面上の合わせ先 → 画像の上の 2 点目 → 図面上の合わせ先 の順にクリックすると、2 点が重なるよう移動・回転・拡大縮小します。
  2 点目の方向へ回転もします。右クリックで「大きさも合わせる」をオフにすると回転と移動だけ (大きさはそのまま)。
  画像以外の図形も同じように合わせられます
- 画像は線や文字の下に表示します。選択は枠の線のクリックか、近くに線などが無ければ画像の中のクリックでも選べます (選んで Delete、または削除モードで画像の中をダブルクリックで削除)
- **最前面へ / 最背面へ** (`DF` / `DB`、図面タブ・修正メニュー・選択中の右クリック): 選択した図形の表示の順番を変えます。
  画像を最前面にすると線・文字より上に、最背面にすると一番下 (線・塗りの下) になります。重なった画像どうしの順番もこれで変えます。印刷・DXF の保存にも反映
- **画像のトリミング** (`IC`、図面タブ「トリミング」・選択中の右クリック): 画像を選んで (またはクリックして)、残す範囲の対角の 2 点を指定します。
  範囲は画像の縦横に沿った四角です。隠した所は消えず、広く取り直すか `R` (右クリック「トリミングを解除」) で戻せます。印刷・DXF の保存にも反映
- プロパティで幅 (縦横比は保つ)・透明度を変えられます。移動・回転・複写・削除もできます
- 大きな画像でも止まらないよう、画素の読み込みは裏で行います (読み込み中は枠と「読み込み中…」を表示)。
  全体は縮小版 (長辺 2048 画素) で表示し、拡大すると止まってから見えている範囲だけを細かく読み直します
- DXF には画像を埋め込まず、画像ファイルの場所を保存します (別の場所へ移すときは DXF と同じフォルダに画像を入れておけば読めます)。
  SFC には画像を保存できません

### 縮尺

作図 > 縮尺設定 (`SC`、またはステータスバー・シートタブ右端の「シートの縮尺 1:500」) で、表示中のシートの縮尺を設定します。
縮尺は、印刷するときの大きさと、文字高・図枠・記号・路線の注記など「用紙上の mm」で決まる物を実寸 (m) に換算するのに使います。計測 (距離・面積) は図面上の実寸です。
縮尺を変えるときは、すでに描いた図形の扱いを選びます (前回の選択を覚える)。

- **図面をそのまま (図寸固定・既定)**: 図面全体を縮尺の比で拡大・縮小 (原点 0,0 を基準) し、表示も同じだけ広げるので画面の見た目は変わりません。
  計測の値は新しい縮尺の値になります (1:100 で 10m の線は 1:250 で 25m)。文字・記号・図枠は用紙上の大きさのまま。
- **実寸を保つ (実寸固定)**: 線などの長さ (計測の値) はそのまま。図枠だけ外枠の左下を基準に新しい縮尺の大きさにします (A3 の図枠は 1:100 で 38m、1:250 で 95m)。測量座標に合わせて描いた図面向け。

どちらも表題欄の縮尺の文字は新しい縮尺に書き換え、元に戻すで一度に戻せます。図枠の窓で縮尺を変えたときは「実寸を保つ」です。
縮尺は DXF の DIMSCALE に保存されます。

### 座標設定

作図 > 座標設定 (`CS`) で、図面を測量座標に合わせます。
基準点1 をクリック → その測量座標「X,Y」を入力 → 基準点2 をクリック → 測量座標を入力、で図面全体を移動し (基準点1 が測量座標の位置に来る)、
**図面は回さず**、2 点の向きの違いを「測量座標の向き」としてシートに持ちます (画面の見た目の向きはそのまま)。
ステータスバーの座標・`sX,Y` の入力・計測の ΔX / ΔY と方向角・プロパティの測量座標・座標読込・路線・方位記号 (自動) はこの向きで計算します。
基準点2 で Enter なら移動のみ (向きは 0)。測量座標の向きは DXF / DWG に保存します (JWW・SFC・P21 には保存されません)。
2 点間の距離が測量値と 0.5% 以上違うときは警告します (大きさは変えません)。Ctrl+Z で戻せます。
座標入力では `sX,Y` で測量座標を直接指定できます。ステータスバーには測量座標 X(北)/Y(東) を表示します。

### 平面直角座標系

作図 > 平面直角座標系の系番号 (`ZN`、またはステータスバーの「座標系: ○系」) で I〜XIX 系を設定します。
設定するとステータスバーにカーソル位置の緯度・経度 (JGD2011, GRS80, 国土地理院の換算式) を表示します。
系番号は DXF のユーザー変数 USERI1 に保存。「新しい図面の既定にする」で次回以降の既定にもできます。

### 図枠 (外枠・表題欄)

作図 > 図枠 (`FR`) で、用紙 (A0〜A4)・縮尺・余白を選び、外枠の左下をクリックして配置します。
外枠は用紙端から余白 (既定 20mm) 内側の太線、表題欄は右下 100×60mm (工事名/図面名/作成年月日/縮尺・図面番号/会社名/事業者名)。
縮尺に合わせて実寸 (m) に拡大して作図します (1/500 なら用紙 1mm = 0.5m)。
外枠の大きさは用紙と縮尺で決まるので (A3・1:100 なら 38m × 25.7m)、描いてある図形に対して大きすぎ / 小さすぎることがあります。
窓には描いてある図形の大きさも出し、収まらない・小さめのときは知らせます。「図形が収まる縮尺にする」を押すと、図形 (図枠を除く) が外枠の中
(表題欄を除き、用紙上 10mm の余裕) に収まる、いちばん大きく描ける縮尺 (1:10, 20, 25, 50, 100, 200, 250, 500 … ) を選びます。
配置のとき Enter を押すと、図形が枠の中央 (表題欄を避けた場所) に来るように置きます。置いた枠が画面からはみ出していれば枠全体を表示します。
レイヤは CAD 製図基準に合わせて D-TTL / D-TTL-FRAM / D-TTL-LINE / D-TTL-TXT。入力内容は次回に引き継がれます。

### キー割り当て

「設定 > キー割り当て」で、各コマンド (線・削除モード・移動など) に好きなキーを割り当てられます。
Ctrl / Shift / Alt との組み合わせも可。設定は `%APPDATA%\CivilCad\settings.json` に保存されます。
英字キー単独 (例: `E`) はコマンド欄が空のときだけ働きます (IME オン時は無効)。

### 作図入力バー

線・ポリライン・円・円弧・文字の作図中だけ、作図領域の上に入力バーが出ます。
- 線・ポリライン: 長さ (m)・角度 (°, 東 = 0° 反時計回り)。長さを入れるとクリックした方向にその長さで、角度を入れるとその向きに線を引く。
  角度の横の「刻み」で **90°刻み・45°刻み・15°刻み** を選ぶと、線の向きが東 (0°) からその刻みの一番近い向きにそろう
  (角度の欄に数値を入れているときはその角度、端点などにスナップしているときはスナップした点が優先)
- 円: 半径 (m)。入れておくと中心をクリックするだけで円ができる
- 円弧: 半径 (m)。入れておくと 始点 → 終点 → 膨らむ側 (表示中の円弧の近く) をクリックで作図。空欄なら 3 点円弧
- 文字: 文字高 (用紙 mm)
- 共通: 線幅・**線種**・色 (これから描く図形に付く。プロパティの「作図の設定」と同じ値)
  - 線種: 実線・破線・点線・一点鎖線・二点鎖線。線・ポリライン・矩形・円・円弧に効く。描いた後もプロパティの「線種」で変えられる
  - 模様の長さは用紙上の mm (破線 3mm・間 1mm、点線 1.5mm 間隔、鎖線 10mm など) で、縮尺によらず印刷したとき同じ見た目。
    縮小表示で模様が細かくなりすぎるときは実線で表示
  - DXF / DWG (DASHED・DOT・DASHDOT・DIVIDE)・SFC (SXF の既定義線種)・JWW (点線1・点線3・一点鎖1・二点鎖1)・PDF 印刷に書き出す。
    読み込み時は HIDDEN・CENTER・PHANTOM など他の CAD の線種名も近い線種にする
数値の欄は空欄なら「マウスで決める」。入れた値は空欄にするまで次のコマンドでも使われます。

キー操作 (入力バーの下の段に、今使えるキーのガイドが出ます):
- `Tab`: 作図中に押すと数値の欄へ。欄の中では次の欄へ (線なら 長さ → 角度)
- `Shift+Tab`: 長さ・半径の単位を mm → cm → m の順に切り替え (欄の横の単位ボタンのクリックでも可)。
  欄の数字はそのままで単位だけ変わる (例: `500` は mm → 500 mm、cm → 500 cm、m → 500 m)。確定したあとに切り替えても同じ
- `Enter`: 確定して作図に戻る / `Esc`: 取り消して作図に戻る
- Alt+Tab は Windows のウィンドウ切り替えに使われるため、単位の切り替えは Shift+Tab にしています
固定はマウスのクリックだけに効き、コマンド欄に打ち込んだ座標はそのまま使います。

### 背景色・グリッド

- **グリッド**: 作図領域の背景に方眼の線を表示します (5 本ごとに少し濃い線、図面の原点 (0, 0) にそろう)。
  右下の「グリッド」ボタン・`F7`・コマンド `GR` で表示 / 非表示、横の欄で間隔 (m) を選ぶか入力して Enter。
  「自動」は拡大率に合わせて 1・2・5・10… m から選び、指定した間隔が画面で細かすぎるときは 10 倍ずつ間引きます
- **背景色**: 設定 > 「表示」タブで、濃い灰 (既定)・黒・紺・灰・薄い灰・白・クリームから選ぶか、色コード (#RRGGBB) を入力。
  明るい背景では白い線・文字を黒で、暗い背景では黒い線を白で表示します (図形の色は変わらず、保存・印刷にも影響しません)
- **グリッドへのスナップ**: 右下のスナップツールバーの「グリッド点」をオンにすると、カーソルがグリッドの交点に吸い付きます (既定はオフ)。
  グリッドを表示しているときだけ効き、表示中の間隔 (間引いているときは間引いた間隔) の交点を使います。線の端点・交点など図形のスナップが近くにあればそちらが優先
- グリッドの表示・間隔と背景色は次回の起動でも引き継ぎます

### スナップ

端点 □・中点 △・中心 ○・四半円点 ◇・挿入点 ×・交点 ×・垂線の足 ⊥・接点・近接点 (砂時計)。
カーソル付近で最も近い候補に吸着し、種類名をマーカーの横に表示します。
垂線の足・接点は直前に指定した点 (線の始点など) が基準。近接点は他に候補が無いときだけ使います (既定はオフ)。
種類ごとのオン/オフは設定ファイルに保存されます。

### プロパティ

右側のプロパティパネル (`PR` で開閉、既定で表示) に選択中の図形の情報を表示します。
レイヤ・色・線幅、線の長さ、円・円弧の半径、文字の内容・文字高 (用紙 mm) はその場で書き換え可能 (Enter で確定、Ctrl+Z で戻せる)。
複数選択時は内訳と長さ合計を表示し、レイヤ・色・線幅、文字高・幅係数 (文字だけに適用) をまとめて変更できます。
何も選択していないときは「作図の設定」として、これから描く図形のレイヤ・色・線幅・文字高を設定できます。
線幅は画面上も太さに反映されます (1mm ≒ 3px)。
ヘッダの ⧉ ボタン (またはヘッダのダブルクリック、表示 > プロパティをフロート、`PRF`) で別ウィンドウに切り離せます。
⇲ で右側に戻ります。フロート状態とウィンドウの位置・大きさは次回に引き継がれます。

### レイヤ

レイヤパネルは `LA` (表示 > レイヤパネル、ツールバー、ステータスバーの「レイヤ: ○○」) で開閉します。起動時は閉じています。
見出し右の ⧉ (または見出しのダブルクリック、`LAF`) で別ウィンドウに切り離せ、⇲ で左側に戻ります。

表示・ロック・色・名前の編集、現在レイヤ (ダブルクリック)、単独表示、レイヤ上の図形を全選択、
選択図形を別レイヤへ移動、「現在レイヤのみ編集」モード (他レイヤはグレー表示・選択不可)。

### 路線作成 (路線パネル)

路線タブの「路線作成」(`RL`) で左に **路線パネル** が開きます (⧉ で別ウィンドウにも)。

1. 表に 始点 → IP → … → 終点 を入れる。列は **属性** (始点 / IP / クロソイド / 終点)・**点名**・**X (北)**・**Y (東)**・**R**・**A1**・**A2**
   - 「図面から追加」: 図面で点を順にクリック (Enter で終わる。最初が始点・最後が終点)。「選んだ行を図面で指定」で 1 行の座標を置き直す
   - 直接入力のほか、Excel などの表を選んだセルから **Ctrl+V** で貼り付け (見出し行は飛ばす。BP・EP・CL なども属性として読む)、**Ctrl+C** でコピー、Delete でセルを空に
   - IP の R が空・0 なら折点。クロソイドは R と A1 (A2 が空なら A1 と同じ)
2. 「計算」で延長・曲線数を出し、**通過点** を選ぶ: No.杭の間隔 (既定 20m。10・25・50・100m や任意の値)、中間杭 (なし・5・10m など。No.1+10.00 のように入る)、
   主要点 (BC・EC・KA・KE など) を含めるか、通過点を座標管理に登録するか、幅 (路肩線・幅杭)。選び直すと通過点一覧がすぐ変わる (一覧は Ctrl+C でコピーできる)
3. 「作図」で中心線・No.杭・中間杭・主要点・幅を作図し、選んでいれば通過点を点名付きの点 (タグ: 中心杭・中間杭・主要点) にして座標管理に登録する。
   同じ路線名で作図し直すと置き換え。作図した路線は測点照会 (`ST`) に使う

### 路線計算 (IP法)

**路線作成** (路線 > 路線作成、`RL`): 図面上で BP → IP1 → … → EP の順にクリック (スナップ・座標の入力も可。一つ戻すで直前の点を取り消し) し、Enter で確定すると、
クリックした点 (測量座標) が入った路線計算の窓が開きます。各 IP の R・A1・A2 と幅を入れて「作図して閉じる」で作図します。路線名は使っていない「路線N」になります。

**幅 (路肩線・幅杭)**: 路線計算の窓の「幅 左 / 右 (m)」に中心線からの幅をカンマ区切りで入れると (例: 左 `3.0, 5.5`・右 `3.0`)、
「路肩線」で幅ごとに中心線と平行な線 (円曲線・クロソイドにも沿う。レイヤ 路線-路肩線)、
「幅杭」で測点ごと (と起点・終点) にいちばん外の幅の点に小さな円と、左右の幅杭を結ぶ線 (レイヤ 路線-幅杭) を作図します。

IP 表 (名称, X, Y, R, A1, A2) を入力 → 主要点 (BC/EC, KA/KE)・曲線諸元・測点ごとの座標を計算し、
中心線・IP 線・測点・主要点を作図します。Excel から表を貼り付け可能。同じ路線名で再作図すると置き換わります。
「任意点計算」タブで測点+幅 → 座標、`ST` コマンドで図面上の点 → 測点+幅。

**路線 XML (LandXML / J-LandXML) の読み込み**: 路線 > 路線 XML 読込 (`RX`)、または路線計算ダイアログの「XML 読込」。
平面線形 (CoordGeom の直線・円曲線・クロソイド) から、各曲線の前後の接線の交点を IP、円曲線の半径を R、
クロソイドのパラメータを A1/A2 とした IP 表を作り、路線名・開始追加距離 (staStart)・測点間隔 (Interval) も読み込みます。
IP 名はファイルの AlignPIs にあればその名前。直線どうしの継ぎ目は R=0 の折れ点になります。
1 ファイルに複数の路線があるときは選択します。卵形クロソイドなど IP 法で表せない線形は読み込めません。縦断・横断は未対応。
