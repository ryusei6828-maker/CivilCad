# CivilCad

土木向けの 2D CAD (Windows / C# .NET 10 / WPF)。

## 構成

| プロジェクト | 内容 |
|---|---|
| `src/CivilCad.Core` | 幾何 (Vec2, Box2)、図形、レイヤ、図面、Undo/Redo |
| `src/CivilCad.Alignment` | 路線計算 (IP法・クロソイド・測点・縦断曲線)。UI に依存しない |
| `src/CivilCad.App` | WPF アプリ (作図画面、ツール、レイヤパネル、路線計算ダイアログ、DXF 入出力) |
| `tests/CivilCad.Tests` | xUnit テスト |

## 実行

```
dotnet run --project src/CivilCad.App
dotnet test
```

### 配布用 exe の作成

.NET 同梱の単一 exe (`publish\CivilCad.exe`、インストール不要) を作る:

```
dotnet publish src/CivilCad.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=None -o publish
```

## 座標系

- CAD 内部座標: **x = 東, y = 北** (m)。コマンド欄の座標入力もこの順。
- 路線計算ダイアログ・計測結果の表示は測量座標 **X = 北, Y = 東**。
- 方向角は測量の定義 (北 = 0°, 時計回り)。

## 操作

画面上部のツールバーは、左に いつも使うボタン (新規・開く・保存・戻す・やり直し)、右に種類ごとのタブがあります:
**描画** (線・ポリライン・円・円弧・垂線・文字・ハッチング・塗りつぶし)、**修正** (移動・複写・回転・オフセット・トリム・延長・結合・削除)、**図面** (図枠・縮尺・座標・座標系・座標読込)、
**計測** (距離・面積)、**路線** (路線計算・XML 読込・測点照会)、**表示** (全体表示・レイヤ・プロパティ)。
メニューも同じ分け方です。

| 操作 | 方法 |
|---|---|
| ズーム / パン / 全体表示 | ホイール / 中ボタンドラッグ / 中ボタンダブルクリック |
| 選択 | クリックでその図形だけを選択、Shift+クリックで追加 (選択済みなら解除)、ドラッグで範囲選択 (ドラッグの向きは問わない。Shift+ドラッグで追加)、空き部分クリックで選択解除。文字を選ぶとプロパティ (右側) が開き、中身・大きさを変えられる |
| 範囲選択の方法 | 右下の「範囲選択」で **全体** (範囲に完全に入る図形) / **一部** (範囲に少しでもかかる図形) を切り替え。削除モードも同じ。設定は次回も引き継ぐ |
| スナップの種類 | 右下のスナップツールバー: 「スナップ」で全体のオン/オフ、右の 端点・中点・中心… の各ボタンで種類ごとにオン/オフ |
| 座標入力 | `x,y` 絶対、`@dx,dy` 相対、`@距離<角度` 極座標 |
| スナップ / 直交 | F3 / F8 (スナップの種類は右下のスナップツールバー、または 設定 > スナップの種類) |
| 元に戻す / やり直し | Ctrl+Z / Ctrl+Y |
| コマンドのキャンセル | Esc (作図領域・コマンド欄のどちらにカーソルがあっても効く) |
| 連続作図 | コマンドは 1 つ描いても終わらず、Esc を押すまで続けて使える (円・円弧・文字・ポリライン・ハッチング・垂線・計測・移動など)。線・ポリラインは Enter でその線を終えて次の線へ、何も描いていないときの Enter はコマンド終了 |
| 右クリック | コマンド中: **一つ戻す** (直前に指定した点を取り消す。線では引いた線も消える)・**最初からやり直す**・確定 (ポリラインの確定など)・コマンドを終了。選択中: 移動・複写・削除・選択解除、元に戻す / やり直し |
| 一つ戻す (キー) | コマンド欄が空のとき Backspace |

コマンド: `L` 線, `PL` ポリライン (`C` で閉じる), `C` 円, `A` 3点円弧, `PE` 垂線, `T` 文字 (`H=数値` で大きさ。既定は画面上で一定の大きさ、下記), `H` ハッチング, `FI` 塗りつぶし, `J` 結合,
`M` 移動, `CO` 複写, `RO` 回転, `O` オフセット, `TR` トリム, `EX` 延長, `ED` 文字変更, `E` 削除モード (クリックした図形をその場で消す、ドラッグで範囲内の図形をまとめて削除 (全体 / 一部 は範囲選択の方法に従う)、Esc で終了), `DI` 距離・方向角, `AA` 面積, `RC` 路線計算, `ST` 測点照会, `ZE` 全体表示

### 文字の大きさ

文字ツール (`T`) の文字は、既定で **画面上で一定の大きさ** (縮尺・拡大率によらず同じ大きさに見える、既定 16px) で書きます。
作図入力バーの「画面で一定の大きさ」を外すと、従来どおり用紙上の mm を図面の縮尺で m に換算した大きさになります。
プロパティの「画面で一定 (px)」で文字ごとに切り替えられます (空欄にすると今の大きさで図面に固定)。
ファイルに保存するときは、画面で一定の文字を用紙上 1px = 0.26mm の大きさ (縮尺で換算) にして書きます。

### 修正コマンド

| コマンド | 使い方 |
|---|---|
| 回転 `RO` | 図形を選択 → 基点 → 角度を数値 (度、反時計回りが +) で入力するか向きをクリック。`C` で元を残して回転複写 |
| オフセット `O` | 距離 (m) を入力 → 図形をクリック → ずらす側をクリック。距離はそのまま続けて使える。線・円・円弧・ポリライン (角は留め継ぎ) |
| トリム `TR` | 境界にする図形をクリックして Enter (何も選ばず Enter で全図形。先に選択していればそれが境界) → 切り取る部分をクリック。Shift+クリックで延長 |
| 延長 `EX` | 境界を選んで Enter → 伸ばす端の近くをクリック。線・円弧・開いたポリライン。Shift+クリックでトリム |
| 文字変更 `ED` | 文字をクリックすると、入力の窓で中身を変えられる (Enter で変更、Esc でやめる)。続けて別の文字も変えられる。選択中 (コマンドを使っていないとき) は文字のダブルクリックでも。色・位置・大きさはそのまま。Ctrl+Z で戻せる |
| 結合 `J` | 図形を選択して実行。同じ直線上の線は 1 本に (間が空いていても埋める)、同じ円上の円弧は 1 つに (一周すれば円)、そのうえで端点が用紙上 0.05mm 以内でつながる線・開いたポリライン・円弧を 1 本のポリラインに (円弧は細かい折れ線になる。始点に戻れば閉じ、塗りつぶし (FI) の範囲に使える) |

トリム・延長はカーソルを合わせると、消える部分を赤、伸びた形を水色で先に表示します。
オフセットしたポリラインが自己交差しても整理しません。

スナップの「頂点」はポリラインの途中の点 (閉じたポリラインは全点) です。開いたポリラインの始点・終点は「端点」。

### ハッチング

ハッチングは 1 つの図形 (境界 + 平行線の模様) として扱い、ハッチ線をクリックすると全体がまとめて選ばれます
(移動・複写・削除・レイヤ変更もまとめて)。選択中は境界も表示します。
プロパティでは種類・面積を表示し、角度と間隔 (用紙 mm) を変更できます。

作図は 描画 > ハッチング (`H`):
- 閉じた図形 (閉じたポリライン・始点に戻るポリライン・円) の**内側をクリック**すると、その範囲にハッチング。
  いちばん小さい囲みが外形になり、その内側にある閉じた図形は中抜き (島) になります。カーソルを乗せると対象の範囲を破線で表示
- 閉じた図形が無い所では、**クリックした点を頂点**とする範囲を作り、Enter (または右クリック > 範囲を確定) で確定
- 作図入力バーで 種類 (斜線 / クロス / 塗りつぶし)・角度 (°)・間隔 (用紙 mm、縮尺で m に換算)・透明度 (%) を指定。Esc で終了
- **透明度**: 0% = 不透明、50% = 半透明。プロパティでも変更でき (複数のハッチングをまとめて変更可)、DXF に保存されます (SFC には透明度が無いため保存されません)。
  塗りつぶしは線・文字より下に描くので、塗っても線や文字は隠れません

### 塗りつぶし・結合

- **結合 (`J`)**: 端点どうしがつながった線・開いたポリライン・円弧を選択して実行すると、1 本のポリラインになります
  (順番・向きがばらばらでも可、用紙上 0.05mm までの隙間はつながっているとみなす)。一周して始点に戻れば閉じた図形になります。円弧は細かい折れ線になります
- **塗りつぶし (`FI`)**: 閉じた図形 (閉じたポリライン・円) を選択してから実行すると、まとめて塗ります (選択した図形の内側にある選択図形は中抜き)。
  選択せずに実行した場合は、塗りたい範囲の内側をクリック (ハッチングと同じ)。色は 作図の設定 (入力バー・プロパティ) の色、透明度は入力バーで指定
- 例: ばらばらの線で囲った範囲を塗る → 線を選択 → `J` で結合 → そのまま `FI`

### 計測結果の記入

距離 (`DI`)・面積 (`AA`) で計測すると、結果の文字 (例: `L=12.345m`、`A=123.456m²`) がカーソルに付いて動き、クリックした位置に置けます。
距離の文字は計測した線に沿った向き (逆さまにならない向き)、面積の文字は水平です。Enter で置かずに次の計測へ、
右クリック > 一つ戻す で計測の最後の点に戻れます。置いた文字は普通の文字として編集・移動できます (Ctrl+Z で取り消し)。
作図入力バーで「結果を文字で記入」のオン/オフ、文字高 (用紙 mm)、小数桁、方向角 / 周長も記入するかを設定できます。色・線幅は作図の設定のもの。

**計測結果は CAD 上の長さに図面の縮尺を掛けた値** です (面積は縮尺の 2 乗)。例: 縮尺 1:100 で CAD 上 1cm → 100cm。
単位は入力バーで mm / cm / m から選べます。メッセージ欄には CAD 上の値も併記します。
※ SFC から開いた図面は実寸 (m) で取り込んでいるため、計測結果は「実寸 × 縮尺」になります。

### 垂線

`PE` (描画 > 垂線): **基準の線** (線・ポリライン・円・円弧) をクリック → **線上の点** (垂線の足。スナップ可、線の延長上も可) を指定 → **終点** を指定。
足に直角の印を表示します。円・円弧では中心を通る向きに引きます。入力バーの「長さ」を入れると、終点はクリックした側にその長さで決まります。
1 本引くと同じ基準の線のまま続けて引けます (別の線にするには右クリック > 一つ戻す、終了は Esc)。

ファイル:
- SFC: ユーザ定義ハッチング (fill_area_style_hatching_feature) を模様ごと読み書き。既定義ハッチングは 45° の斜線 (用紙 2mm 間隔) で表示
  (CAD が用紙外に置く管理用の "Area_control" は読みません)。中抜きのある塗りつぶしも読み込みます
- DXF: HATCH を読み書き (境界の線・円弧・楕円・ポリライン・スプラインに対応)。破線の模様は実線で表示
- 他の CAD がハッチングを 1 本ずつの線に分解して保存した図面は、ただの線として読み込まれます

### シートタブ

図面ごとにタブ (シート) で開きます。新規 (Ctrl+N / タブ右の ＋)・開くは新しいタブになり (空のタブは使い回し)、
同じファイルを開くとそのタブに切り替わります。各タブにはファイル名と縮尺・平面直角座標系 (例: 1:500 ・ II系) を表示し、
タブバー右端に表示中のシートの縮尺・座標系を出します (クリックで変更)。
未保存のタブには * が付き、閉じるとき・終了時に確認します。Ctrl+Tab / Ctrl+Shift+Tab で切り替え、タブの × か中ボタンで閉じます。
表示位置・路線データはシートごとに保持します。

### ファイル

- 開く・保存: DXF / DWG / JWW (Jw_cad) / SFC・P21 (SXF レベル2)。P2Z (P21 の ZIP) も開けます。
- P21: STEP AP202 (ISO 10303-21)。SCADEC のライブラリの書き方 (SFC のフィーチャ 1 つ = 決まった形のインスタンスの組) に合わせ、
  保存は SFC と同じ内容を AP202 に直したもの、読み込みは AP202 を SFC のフィーチャに直して SFC と同じ取り込み方をします。
  寸法は SFC と同じく、長さ寸法の寸法線と値・引出線と文字・その他の寸法とバルーンの文字を取り込みます。
- DWG: AutoCAD R14 以降の形式を読み込み (ACadSharp)。線・ポリライン・円・円弧・楕円・スプライン (折れ線)・文字・MTEXT・
  ハッチングとレイヤ・色・線幅を DXF と同じ対応で取り込み、ブロック参照は分解します。保存は AutoCAD 2013 形式。
- JWW: Jw_cad の公開データ形式 (jwdatafmt.txt) による。JWW の座標は用紙 mm (原点は用紙の中心) なので、
  「図寸 mm × レイヤグループの縮尺 / 1000」で実寸 (m) に換算します。レイヤは「グループ-レイヤ 名前」(16 進、例 `0-1 中心線`)。
  線・円・円弧・楕円 (折れ線)・実点 (小さな円)・文字・寸法 (線と値)・ソリッド (塗りつぶし)・ブロック (分解) に対応。
  保存はデータ版 700 (Jw_cad 7 以降) で、図面の縮尺を全レイヤグループに使い、用紙は SFC と同じ選び方で、その中心を原点にします
  (図面の元の座標はファイルメモに入れ、CivilCad で読み直すと元の位置に戻ります)。ポリラインは線分、ハッチングの模様は線、
  塗りつぶしは三角形のソリッドになります。「g-l 名前」のレイヤはそのグループ・レイヤに、ほかは空いているレイヤに入ります。
- SFC 保存時は、表題欄・図枠 (レイヤ D-TTL*) を用紙 (mm) に直接、それ以外を図面縮尺の部分図 (実寸 mm) として書き出します。
  レコードの並びは他の CAD (SCADEC) と同じ「定義 → 部分図 → 用紙上の図形 → 用紙 (drawing_sheet) → レイヤ表」。
  レイヤ名は前後の空白を除き、重複は「_2」などで区別、空なら「レイヤn」にして書きます。図形の無いレイヤ "0" は書きません (最大 256 レイヤ)。
  用紙は図枠から A 判を判定 (図枠が無ければ図形が収まる A 判)。白は黒として出力。Shift_JIS に無い文字は \X2\ 表記。
- SFC は用紙 (mm) 上に部分図を配置した形式なので、部分図の縮尺 (例: 1/500) を図面の縮尺とし、
  全体を「用紙 mm × 縮尺 / 1000」で実寸 (m) に換算して取り込みます (部分図の中身は元の実寸に戻る)。
  線・折線・円・円弧・楕円・文字・スプライン・クロソイド・点マーカー・引出線・寸法値・塗りつぶし・シンボル (sfig) に対応。
  ハッチングはハッチング図形として読み込みます (下記)。寸法の補助線・矢印は省略します。

### 座標読込 (SIMA / CSV)

ファイル > 座標読込、図面タブの「座標読込」(`PI`) で座標ファイルの点を図面に配置します。
読み取った点の一覧を確認してから、レイヤ (既定「座標点」)・点名 / 標高の表示・文字高 (用紙 mm)・点の印の大きさを選んで読み込みます。
点は小さな円 (中心にスナップ可) と点名の文字で、測量座標 (X = 北, Y = 東) の位置に置きます。元に戻すで一度に消せます。

- SIMA (.sim): `A01,点番号,点名,X,Y,H` の行。画地 (D00〜D99 の B01) があれば点をつないだ閉じた線も作れます
- CSV (.csv / .txt): 1 行 1 点。区切りはカンマ・タブ・空白。`点名,X,Y[,Z]`、`点番号,点名,X,Y[,Z]`、`X,Y[,Z]`、`点番号,X,Y,Z`、
  `No,点番,点名,X,Y,Z` などの並びを自動で判別し、見出しなど座標の無い行は飛ばします。座標の順は X (北), Y (東)
- 文字コードは Shift_JIS / UTF-8 を自動判別

### 縮尺

作図 > 縮尺設定 (`SC`、またはステータスバーの「縮尺 1:500」) で図面の縮尺を設定します。
文字高・図枠・路線の注記は「用紙上の mm」で指定し、この縮尺で実寸 (m) に換算して作図します。
縮尺は DXF の DIMSCALE に保存されます。

### 座標設定

作図 > 座標設定 (`CS`) で、図面を測量座標に合わせます。
基準点1 をクリック → その測量座標「X,Y」を入力 → 基準点2 をクリック → 測量座標を入力、で図面全体を移動・回転し、
図面の座標 = 測量座標 (x=東=Y, y=北=X) にします。基準点2 で Enter なら移動のみ。
2 点間の距離が測量値と 0.5% 以上違うときは警告します (大きさは変えません)。Ctrl+Z で戻せます。
座標入力では `sX,Y` で測量座標を直接指定できます。ステータスバーには測量座標 X(北)/Y(東) を表示します。

### 平面直角座標系

作図 > 平面直角座標系の系番号 (`ZN`、またはステータスバーの「座標系: ○系」) で I〜XIX 系を設定します。
設定するとステータスバーにカーソル位置の緯度・経度 (JGD2011, GRS80, 国土地理院の換算式) を表示します。
系番号は DXF のユーザー変数 USERI1 に保存。「新しい図面の既定にする」で次回以降の既定にもできます。

### 図枠 (外枠・表題欄)

作図 > 図枠 (`FR`) で、用紙 (A0〜A4)・縮尺・余白を選び、外枠の左下をクリックして配置します。
外枠は用紙端から余白 (既定 20mm) 内側の太線、表題欄は右下 100×60mm (工事名/図面名/作成年月日/縮尺・図面番号/会社名/事業者名)。
縮尺に合わせて実寸 (m) に拡大して作図します (1/500 なら用紙 1mm = 0.5m)。
レイヤは CAD 製図基準に合わせて D-TTL / D-TTL-FRAM / D-TTL-LINE / D-TTL-TXT。入力内容は次回に引き継がれます。

### キー割り当て

「設定 > キー割り当て」で、各コマンド (線・削除モード・移動など) に好きなキーを割り当てられます。
Ctrl / Shift / Alt との組み合わせも可。設定は `%APPDATA%\CivilCad\settings.json` に保存されます。
英字キー単独 (例: `E`) はコマンド欄が空のときだけ働きます (IME オン時は無効)。

### 作図入力バー

線・ポリライン・円・円弧・文字の作図中だけ、作図領域の上に入力バーが出ます。
- 線・ポリライン: 長さ (m)・角度 (°, 東 = 0° 反時計回り)。長さを入れるとクリックした方向にその長さで、角度を入れるとその向きに線を引く
- 円: 半径 (m)。入れておくと中心をクリックするだけで円ができる
- 円弧: 半径 (m)。入れておくと 始点 → 終点 → 膨らむ側 (表示中の円弧の近く) をクリックで作図。空欄なら 3 点円弧
- 文字: 文字高 (用紙 mm)
- 共通: 線幅・色 (これから描く図形に付く。プロパティの「作図の設定」と同じ値)
数値の欄は空欄なら「マウスで決める」。入れた値は空欄にするまで次のコマンドでも使われます。

キー操作 (入力バーの下の段に、今使えるキーのガイドが出ます):
- `Tab`: 作図中に押すと数値の欄へ。欄の中では次の欄へ (線なら 長さ → 角度)
- `Shift+Tab`: 長さ・半径の単位を mm → cm → m の順に切り替え (欄の横の単位ボタンのクリックでも可)。
  欄の数字はそのままで単位だけ変わる (例: `500` は mm → 500 mm、cm → 500 cm、m → 500 m)。確定したあとに切り替えても同じ
- `Enter`: 確定して作図に戻る / `Esc`: 取り消して作図に戻る
- Alt+Tab は Windows のウィンドウ切り替えに使われるため、単位の切り替えは Shift+Tab にしています
固定はマウスのクリックだけに効き、コマンド欄に打ち込んだ座標はそのまま使います。

### スナップ

端点 □・中点 △・中心 ○・四半円点 ◇・挿入点 ×・交点 ×・垂線の足 ⊥・接点・近接点 (砂時計)。
カーソル付近で最も近い候補に吸着し、種類名をマーカーの横に表示します。
垂線の足・接点は直前に指定した点 (線の始点など) が基準。近接点は他に候補が無いときだけ使います (既定はオフ)。
種類ごとのオン/オフは設定ファイルに保存されます。

### プロパティ

右側のプロパティパネル (`PR` で開閉、既定で表示) に選択中の図形の情報を表示します。
レイヤ・色・線幅、線の長さ、円・円弧の半径、文字の内容・文字高 (用紙 mm) はその場で書き換え可能 (Enter で確定、Ctrl+Z で戻せる)。
複数選択時は内訳と長さ合計を表示し、レイヤ・色・線幅、文字高・幅係数 (文字だけに適用) をまとめて変更できます。
何も選択していないときは「作図の設定」として、これから描く図形のレイヤ・色・線幅・文字高を設定できます。
線幅は画面上も太さに反映されます (1mm ≒ 3px)。
ヘッダの ⧉ ボタン (またはヘッダのダブルクリック、表示 > プロパティをフロート、`PRF`) で別ウィンドウに切り離せます。
⇲ で右側に戻ります。フロート状態とウィンドウの位置・大きさは次回に引き継がれます。

### レイヤ

レイヤパネルは `LA` (表示 > レイヤパネル、ツールバー、ステータスバーの「レイヤ: ○○」) で開閉します。起動時は閉じています。
見出し右の ⧉ (または見出しのダブルクリック、`LAF`) で別ウィンドウに切り離せ、⇲ で左側に戻ります。

表示・ロック・色・名前の編集、現在レイヤ (ダブルクリック)、単独表示、レイヤ上の図形を全選択、
選択図形を別レイヤへ移動、「現在レイヤのみ編集」モード (他レイヤはグレー表示・選択不可)。

### 路線計算 (IP法)

IP 表 (名称, X, Y, R, A1, A2) を入力 → 主要点 (BC/EC, KA/KE)・曲線諸元・測点ごとの座標を計算し、
中心線・IP 線・測点・主要点を作図します。Excel から表を貼り付け可能。同じ路線名で再作図すると置き換わります。
「任意点計算」タブで測点+幅 → 座標、`ST` コマンドで図面上の点 → 測点+幅。

**路線 XML (LandXML / J-LandXML) の読み込み**: 路線 > 路線 XML 読込 (`RX`)、または路線計算ダイアログの「XML 読込」。
平面線形 (CoordGeom の直線・円曲線・クロソイド) から、各曲線の前後の接線の交点を IP、円曲線の半径を R、
クロソイドのパラメータを A1/A2 とした IP 表を作り、路線名・開始追加距離 (staStart)・測点間隔 (Interval) も読み込みます。
IP 名はファイルの AlignPIs にあればその名前。直線どうしの継ぎ目は R=0 の折れ点になります。
1 ファイルに複数の路線があるときは選択します。卵形クロソイドなど IP 法で表せない線形は読み込めません。縦断・横断は未対応。
